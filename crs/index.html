The Brief

Parts, fast — no friction

CRS Automotive required a product-forward web experience for a broad catalogue of automotive parts and components. The core requirement was simple: a buyer should be able to find the right part, understand the specification, and get to checkout without detours.

The site also needed to carry the weight of the febi-red brand — recognisable in the aftermarket parts space — while staying fast and practical across all devices.

The Approach

Dark base, red accent, clear catalogue

A dark base with the febi-red accent used selectively — for primary actions and brand moments — keeps urgency without overwhelming the product content. Part categories are laid out for scanability — part numbers, specifications, and compatibility information surface early so buyers can qualify products quickly.

Built in vanilla HTML, CSS, and JavaScript — no framework overhead. The result is a site that performs on both the broadband workshop computer and the mobile phone a mechanic reaches for mid-job.

Palette

Near-black as the primary surface. Febi-red for actions and brand moments. Off-white for text — maximum contrast on every part card.

Catalogue

Parts are grouped by system — hub, shaft, axle, sensors, wiring — so trade buyers can navigate by knowledge, not search terms.

Product cards

Each part card leads with imagery, then part number and compatibility. The buy path is one action — no unnecessary intermediate screens.

Performance

Zero dependencies. Static HTML deployed on GitHub Pages. Reliable in workshops where connection quality is inconsistent.
